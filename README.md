## 🚀 Selected Projects

### 🤖 Agentic Angular → React Migration

Designed a **four-stage agentic workflow** for migrating a legacy Angular codebase to React.

* Codebase analysis and business-logic extraction
* Migration planning and risk assessment
* Phased implementation using structured engineering prompts
* Automated validation and code auditing
* Unit-test generation for regression prevention

A major focus was improving the reliability of LLM-assisted software development through **structured context, milestones, role definition, and continuous validation**.

---

### 🧠 On-Device LLM & Local RAG

Worked on an Android messenger with **offline LLM inference and local RAG**.

* Lightweight model selection for mobile constraints
* Local vector database for retrieval
* Offline question answering
* Peer-to-peer AI model package transfer
* Reduced dependency on server-side inference

The project explored how LLM-based applications can operate under **limited compute, memory, and network availability**.

---

### 📊 Automated Data Cleaning & Anomaly Detection

Built a data-processing pipeline for noisy and unstructured data.

* Text similarity and fuzzy matching
* Data normalization and standardization
* Anomaly detection
* Interactive Power BI dashboards

The goal was to transform noisy raw data into a more structured and reliable source for analysis.

---

### 🧩 AI-Assisted Angular Legacy Upgrade

Developed an AI-assisted workflow for upgrading a legacy Angular project with significant dependency conflicts and breaking changes.

The workflow combined **structured prompting, dependency analysis, automated code transformation, and post-upgrade validation** to reduce migration risk and development effort.
